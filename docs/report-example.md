# Отчёт симуляции Cashback Merge

Оценочный результат одного запуска с этими параметрами.

## Параметры

| Параметр | Значение |
|---|---|
| Конфиг | config\campaign.example.json |
| Игроков | 10000 |
| Стратегия | random |
| Seed | 42 |
| Лимит ходов | 100 |
| Правила появления | 1% с вероятностью 0.85, 2% с вероятностью 0.15 |
| Максимальная награда | плитка 32% |
| Допустимая доля максимальной награды | 0.20 |
